# CodeOrbit Tech — Artificial Intelligence Internship

A collection of six Artificial Intelligence and Machine Learning projects completed as part of my **Artificial Intelligence Internship at CodeOrbit Tech**.

The projects demonstrate practical applications of Python, Machine Learning, Natural Language Processing, Computer Vision, classical AI algorithms, and desktop GUI development.

---

## 📌 Internship Overview

**Organization:** CodeOrbit Tech  
**Domain:** Artificial Intelligence  
**Duration:** 2 Months  
**Batch:** IND1  
**Level:** Final-Year B.Tech Student  

This repository contains the source code, datasets, documentation, and supporting files for the six projects completed during the internship.

---

## 🚀 Projects Completed

### 🤖 Task 1 — Rule-Based Chatbot

A simple interactive console-based chatbot developed using Python.

**Key Concepts:**
- Python programming
- `if-elif-else` decision making
- Keyword and pattern matching
- String normalization
- Interactive console communication
- Fallback responses

**Technologies:** Python

📂 **Project:** [`Task-1-Rule-Based-Chatbot`](./Task-1-Rule-Based-Chatbot/)

---

### 🎮 Task 2 — Tic-Tac-Toe with Simple AI

A console-based Tic-Tac-Toe game where the user plays against an intelligent computer opponent.

The AI uses the **Minimax algorithm** to evaluate possible future game states and select the best move.

**Key Concepts:**
- Game state representation
- Minimax algorithm
- Recursion
- Backtracking
- Decision making
- Win/draw detection
- Input validation

**Technologies:** Python

📂 **Project:** [`Task-2-Tic-Tac-Toe-AI`](./Task-2-Tic-Tac-Toe-AI/)

---

### 🖼️ Task 3 — Image Classification Using a Pretrained Model

An image classification application using the pretrained **MobileNetV2** model.

The project provides both a Tkinter desktop interface and a command-line interface for classifying images and displaying the top predictions with confidence scores.

**Key Concepts:**
- Computer Vision
- Transfer Learning
- Pretrained Deep Learning Models
- Image preprocessing
- Model inference
- Top-3 predictions

**Technologies:** Python, PyTorch, Torchvision, Pillow, Tkinter

📂 **Project:** [`Task-3-Image-Classification`](./Task-3-Image-Classification/)

---

### 🎬 Task 4 — Content-Based Movie Recommendation System

A content-based movie recommendation system that recommends similar movies based on their genres and plot descriptions.

The system uses **TF-IDF Vectorization** and **Cosine Similarity** to calculate similarity between movies.

**Key Concepts:**
- Recommendation systems
- Natural Language Processing
- TF-IDF
- Cosine Similarity
- Feature extraction
- Similarity-based ranking

**Technologies:** Python, Pandas, Scikit-learn

📂 **Project:** [`Task-4-Movie-Recommendation`](./Task-4-Movie-Recommendation/)

---

### 💬 Task 5 — Sentiment Analysis on Text Data

A text sentiment analysis system that classifies reviews into:

- Positive
- Negative
- Neutral

The project uses **TF-IDF** for text feature extraction and **Logistic Regression** for classification. It provides both command-line and Tkinter desktop interfaces.

**Key Concepts:**
- Natural Language Processing
- Text classification
- TF-IDF
- Logistic Regression
- Train-test splitting
- Model evaluation

**Technologies:** Python, Pandas, Scikit-learn, Tkinter

📂 **Project:** [`Task-5-Sentiment-Analysis`](./Task-5-Sentiment-Analysis/)

---

### 💼 Task 6 — AI Career Intelligence

A feature-rich AI/ML desktop application designed to analyze resumes, compare them with job descriptions, recommend career paths, identify skill gaps, and generate personalized learning roadmaps.

The application uses explainable NLP techniques rather than black-box models.

**Key Features:**
- Resume analysis
- Educational resume scoring
- Job description matching
- TF-IDF and Cosine Similarity
- Career recommendation
- Skill gap analysis
- Personalized learning roadmap
- Visual analytics
- Session history
- Tkinter desktop interface

**Technologies:** Python, Scikit-learn, TF-IDF, Tkinter, CSV, JSON

📂 **Project:** [`Task-6-AI-Career-Intelligence`](./Task-6-AI-Career-Intelligence/)
